####  Version Control System (VCS)



* version control system means which will manage or maintain /track changes that perform in your project



* With the help of VCS multiple developer and collative /maintain the communication with each others



* ###### key features:



* Version tracking
* Coloration
* Rollback: go back previous state
* Change management: Allow developer to perform changes in the existing functionality and review the code
*  Branching: Branching means allow developer to work on different folder structure.
* 
* 
* ## VCS: Git

#### 

* Git is an open source popular distributed version control system.
* Git is a practical way to perform version control approach.
*  with the help of git we can manage or track the changes that perform in the application or source code
* With the help of git, developer can create branches in their local machine and create the functionality .Once the code is completed developer can move changes to the main branches/server
*
